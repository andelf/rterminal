Using rterminal

        
      

      

        
Input
Type or dictate in the bottom field. Input or Enter inserts text without running it. Empty submission sends Enter; Backspace on an empty field deletes in the terminal.

        
Size
PC size follows the desktop window. Browser size follows this viewport. The Scan button syncs once and freezes that grid; later rotation or keyboard changes only adjust dot padding.

        
Touch scrolling
Swipe vertically in the right third of the terminal, away from the outer 24 px edge. It sends wheel reports in mouse mode and scrolls local history otherwise. Use the left two-thirds for selection and grid panning.

        
Keyboards
System keyboard supports IME and dictation. Screen keyboard avoids the OS accessory bar. Hold a modifier for one second to latch it for the next key. Win/Mac layout switching is above the arrow pad.

        
Connection
Only one browser owns the live connection. If another client is connected, Steal explicitly disconnects it and takes over.
